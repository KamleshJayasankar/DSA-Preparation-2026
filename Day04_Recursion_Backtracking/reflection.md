# Day 04 - Reflection

## What I Learned

- Recursion needs a base case and a recursive case.
- Recursive calls are stored on the call stack.
- The stack unwinds after the base case is reached.
- Work before recursion happens while going down.
- Work after recursion happens while coming back up.
- Factorial can be expressed as a smaller factorial multiplied by the current value.
- Recursion and iteration solve repetition differently.
- Backtracking follows Choose -> Explore -> Undo.
- Backtracking is generally used when multiple possibilities must be explored.
- Not every recursive problem is a backtracking problem.
