# Recursion vs Iteration

## Iteration

Iteration repeats work using loops such as:

- `for`
- `while`

## Recursion

Recursion repeats work through function calls where a function calls itself.

## Main Difference

**Iteration:** repetition is controlled by a loop.

**Recursion:** repetition is controlled through function calls and a base case.

Recursion is especially useful when the problem naturally has a recursive structure, including trees, divide-and-conquer, and backtracking.

Neither approach is automatically better for every problem.
