# Day 13 - Trees & BST Basics

**Date:** 22 September 2026

**Topic:** Trees and Binary Search Tree (BST) Basics

## Trees - Basics
- A tree is a hierarchical data structure made of nodes.
- The top node is the root.
- A node can have child nodes.
- A node with no children is a leaf.
- The connection between two nodes is an edge.
- A subtree is a smaller tree rooted at a node.

## Binary Tree
A binary tree is a tree in which each node can have at most two children: left and right.

## BST - Basics
A Binary Search Tree follows an ordering rule:
- Values smaller than a node are placed in its left subtree.
- Values greater than a node are placed in its right subtree.

This ordering makes searching possible by deciding which side to explore.
