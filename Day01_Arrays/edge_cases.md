# Day 01 Array Edge Cases

## Maximum / Minimum

- Arrays containing only negative numbers
- Maximum or minimum at the first position
- Maximum or minimum at the last position

## Second Largest

- Negative values
- Repeated largest values, because today's interpretation allows duplicates
- Largest value appearing more than once

## Traversal / Sum / Counting

- Single-element arrays
- Arrays containing zero
- Arrays containing only odd or only even values

## Insertion

- Insert at the beginning
- Insert in the middle
- Insert at the end
- No free capacity in the fixed-size array
