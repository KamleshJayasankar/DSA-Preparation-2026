# Day 01 Complexity Reference

| Operation | Time | Extra Space |
|---|---:|---:|
| Array Traversal | O(n) | O(1) |
| Array Sum | O(n) | O(1) |
| Find Maximum | O(n) | O(1) |
| Find Minimum | O(n) | O(1) |
| Count Even Elements | O(n) | O(1) |
| Second Largest | O(n) | O(1) |

## Key Complexity Idea

A single pass through `n` array elements takes `O(n)` time. The basic operations above keep only a constant number of extra variables, giving `O(1)` extra space.
