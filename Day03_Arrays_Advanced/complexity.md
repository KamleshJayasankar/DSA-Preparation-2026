# Day 03 - Complexity Notes

| Operation / Technique | Time | Extra Space |
|---|---:|---:|
| Reverse array with two pointers | O(n) | O(1) |
| Rotate array using reversal | O(n) | O(1) |
| Count possible subarrays | O(1) | O(1) |
| Generate all subarrays | O(n^3) | O(1) excluding output |
| Build prefix sum | O(n) | O(n) |
| Prefix-sum range query | O(1) | O(1) |
| Prefix Sum + HashMap pattern | O(n) average | O(n) |

The important optimization studied today is using in-place reversal for array rotation instead of requiring another array.
