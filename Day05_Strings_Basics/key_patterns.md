# Day 05 - String Patterns

- Use `length()` to determine the number of characters.
- Use `charAt(index)` for character access.
- Use `substring()` to extract a portion.
- Use `equals()` for content comparison.
- Use `equalsIgnoreCase()` when case should not matter.
- Use built-in functions such as `toUpperCase()`, `toLowerCase()`, `trim()`, `contains()`, `startsWith()`, and `endsWith()` for common manipulation/checks.
