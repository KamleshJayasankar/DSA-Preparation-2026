# Day 2 — Search Decision Guide

## Linear Search

Use when the data is not guaranteed to be sorted or when a simple scan is sufficient.

## Binary Search

Use when the search space is sorted and can be reduced by half.

## Modified Binary Search

Use when the search space has additional structure that allows half-space elimination with extra conditions.

## Rotated Sorted Array

Look for the sorted half first. Then decide whether the target can lie inside that half.

## Rotated Minimum

Compare the middle element with the right boundary to determine which side contains the minimum.
